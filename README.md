# Кнопка расписания ИБ-261

Локальный user-plugin Hermes Agent добавляет в Telegram постоянную клавиатуру:

- `📅 Расписание ИБ-261` — сегодня по `Europe/Moscow`;
- `⬅️ Вчера` / `➡️ Завтра` — переход от последней показанной даты;
- `📆 Другая дата` — валидируемый ввод `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`.

## Гарантии

- Текст и PNG создаются из одного DOM официальной страницы ВГТУ.
- Перед сохранением проверяются выбранная группа и дата.
- Скриншот содержит только таблицу выбранного дня.
- Успешная пара «данные + PNG» сохраняется атомарно.
- При сбое разрешён только кэш той же даты, с заметной пометкой и временем получения.
- Если кэша нет, отправляется сообщение о недоступности без подмены скриншота.

Источник: <https://cchgeu.ru/studentu/onlayn-raspisanie/>

## Структура

- `src/ib261_schedule/` — парсер, браузерный снимок, кэш и worker;
- `plugin/` — Hermes/Telegram-интеграция;
- `tests/` — unit- и локальные browser-тесты;
- `.planning/` — план, находки и журнал выполнения.

## Проверка

```bash
uv sync
uv run playwright install chromium
uv run pytest -q
uvx ruff check .
hermes plugins doctor ./plugin --ci
```

Проверка источника вручную:

```bash
uv run python -m ib261_schedule.worker --date 2026-09-08
```

На текущем хосте официальный сайт отвечает Chromium кодом `403`; поэтому до изменения egress первый запрос корректно вернёт «источник недоступен». Непроверенные или самостоятельно нарисованные изображения не используются.

## Установка в текущем профиле

Плагин установлен как user-plugin через ссылку:

```text
~/.hermes/plugins/ib261-schedule -> <project>/plugin
```

Настройка чата хранится в Hermes config как `plugins.entries.ib261-schedule.settings.chat_id`. Для повторной установки клавиатуры после запуска доступна команда `/ib261`.
